# Algorithm reference

`calculations.py` implements Python nutrition and performance formulas matching the TypeScript production fixtures. The browser uses the actual bundled MediaPipe neural pose model; rep counting, form thresholds, scoring, habit risk and recommendations are deterministic. No fabricated trained classifier or accuracy is included. See `docs/ALGORITHMS.md` for reproducibility, input formats and limitations. Execute `.venv/bin/python -m pytest backend/tests -q` after installing the Python lock.
